# 页码映射与经济史引文核验

## CSV 格式

`--page-map` 接收 UTF-8（可带 BOM）CSV。`pdf_page` 始终是原始完整 PDF 的从 1 开始页码，分段转换时不重新从 1 编号。

```csv
pdf_page,printed_page,verified,note
21,8,true,人工核对原图下方印刷页码及正文
197,184,false,候选值尚未与原图核对
```

这些行只是格式示例，不是通用映射，不应作为某本书的已核验结果。wrapper 校验格式/重复/范围以及核验说明，**不会自动证明 CSV 的声明是真的**；Codex 必须核对原页才能填写 `true`。

输出 `page_map.csv` 多出锚点、Marker 索引、文字核验状态、文本字数，可复制为新的输入映射。不要一键把所有 `verified` 改成 true。

印刷页码是字符串，可写 `iv`、`附录3`、`12–13`（一图两页）或 `无印刷页码`，需在 note 解释对应关系。若一图两页，还应核对左右页阅读顺序与具体引文位置；MD 仅有整个 PDF 页的锚点，不能声称已提供左右页独立锚点。页眉/页脚中出现的金额、章节号和目录里的页数不能误当印刷页码。

## 示例定位

```markdown
<a id="pdf-page-000021"></a>

## 来源定位：PDF 第 21 页｜原书印刷页码：8（已核验）

该页 OCR 原文……
```

`（已核验）` 只意味着映射 CSV 对印刷页码有核验记录。文字是否已核对是独立维度，自动转换默认 `text_status=unreviewed`。没有映射时显示“待核”，即使页末 OCR 文字恰好为 `8`，也不据此自动确认。

## 引文核验记录

正式使用某段史料时，在项目中记录 source_sha256、PDF 页码、印刷页码、锚点、引文或金额、核验结论与差异。检查原书书名、卷辑、出版单位与年份，缺失书目信息不补造。

已核对的文字可另写 `verified_transcript.md`，保留原始 MD、raw 与修改日志。校对可能纠正 OCR，但不得悄悄改动原书本身的错误；需要订正时标明“原文如此”或用有据的校勘说明。

全书引用准备状态不能只取决于程序退出码：

| 状态 | 可用范围 |
|---|---|
| 页边界确认，印刷页码待核，文字未校 | 搜索、阅读、回查 PDF |
| 印刷页码已核，文字未校 | 准确定位原页，仍需核验引文 |
| 引用段落与原图、印刷页码均核对 | 使用该段引文；不能外推全书校对完成 |

页边界丢失、重复、乱序或元数据冲突时，程序拒绝生成可引用的最终结果，保留 raw 供修复；不得通过简单依次加页码掩盖错误。
